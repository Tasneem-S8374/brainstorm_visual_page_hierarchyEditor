# Visual Page Hierarchy Editor

A visual editor built with React that allows users to manage and visualize page hierarchies and reorder Home page sections using drag and drop.

This project demonstrates component architecture, state management, UI/UX design, and graph-based layouts.

---

## 🚀 Features

- Visual page hierarchy using React Flow
- Auto layout using Dagre
- Drag & drop reordering for Home sections
- Zoom, pan, minimap controls
- Save hierarchy to localStorage
- Load hierarchy from localStorage
- Export hierarchy as downloadable JSON
- Highlight nodes on click
- Scrollable Home node panel

---

## 🛠 Tech Stack

- React
- React Flow
- TailwindCSS
- @dnd-kit
- Dagre
- JavaScript (ES6+)

---

## 📦 Setup Instructions

Clone the repository and run:

```bash
npm install
npm start
```
